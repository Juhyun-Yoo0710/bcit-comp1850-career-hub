# Career Restart Resource Hub

BCIT COMP1850 (Web Development I) final project — a static resource site built with HTML/CSS/JS to help newcomers and career-changers in Canada find government, job-search, learning, and networking resources.

**Live demo:** https://juhyun-yoo0710.github.io/bcit-comp1850-career-hub/

## Pages

- `html/index.html` — home page and personal journey
- `html/government_resources.html` — government support programs
- `html/job_boards.html` — job search platforms
- `html/learning_resources.html` — skills/learning resources
- `html/networking.html` — networking organizations
- `html/lorem_ipsum.html` — layout/content test page

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step or framework. Open `html/index.html` directly in a browser, or serve the folder with any static file server.

## Notes

Logos in `images/` belong to their respective organizations and are used only as reference links to those resources.
